# Changelog

## 0.1.0 — 2026-10-14

Initial GitHub source release of the local implementation completed on 2026-10-13: exact-byte pinned Ed25519 scope verification, independent hostname/destination CIDR checks, explicit decision-time binding, durable append-only decision logs, and read-only chain/checkpoint verification. Zero dependencies and offline tests/examples. This source release does not authorize client testing, grant a scope signature, or publish an npm package.
